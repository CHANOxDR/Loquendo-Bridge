# Contributing

Gracias por querer mejorar LoquendoBridge.

1. Haz un fork del repositorio.
2. Crea una rama para tu cambio.
3. Mantén el proyecto compatible con .NET Framework 4.8 y x86.
4. No añadas archivos propietarios de Loquendo.
5. Describe claramente el cambio en tu pull request.

Los cambios que faciliten configuración, diagnóstico, integración con OBS/Streamer.bot o compatibilidad con más dispositivos de audio son bienvenidos.
