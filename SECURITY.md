# Security

No publiques claves, tokens de Twitch, credenciales ni archivos propietarios de Loquendo en issues o pull requests.

Si encuentras un problema relacionado con ejecución de comandos, tratamiento de texto de espectadores o rutas de archivos, repórtalo sin incluir información sensible.

La integración recomendada usa Base64 para transportar el texto de Streamer.bot y evita pasar directamente el mensaje del espectador a CMD.
