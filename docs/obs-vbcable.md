# OBS + VB-CABLE

Página oficial de VB-CABLE:

https://vb-audio.com/Cable/

## Flujo

`LoquendoBridge -> CABLE Input -> CABLE Output -> OBS`

## OBS

1. Añade `Captura de entrada de audio`.
2. Nombre recomendado: `Loquendo TTS`.
3. Dispositivo: `CABLE Output (VB-Audio Virtual Cable)`.
4. Si quieres escucharlo tú mismo, abre Propiedades avanzadas de audio y usa `Monitorizar y emitir`.
5. En Ajustes de OBS selecciona tus audífonos como dispositivo de monitorización.

No necesitas mantener Loquendo TTS Director, PowerShell ni CMD abiertos durante el stream.
